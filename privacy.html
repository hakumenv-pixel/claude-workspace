プライバシーポリシー

最終更新日: 2026年10月30日

1. 対象

本ポリシーは、個人用ツール「claude-workspace」（以下「本アプリ」）に適用されます。本アプリの利用者は開発者本人のみです。

2. 取得する情報

本アプリは、利用者本人が許可した範囲で、Google アカウントの Gmail のメール、Google ドライブのファイル、Google カレンダーの予定にアクセスします。

3. 情報の利用目的

取得した情報は、利用者本人の指示に基づき、メールの確認・整理・作成、ファイルの閲覧・管理、予定の確認・管理を行うためにのみ使用します。

4. 情報の保存

認証情報（アクセストークン）は利用者本人の PC 内にのみ保存されます。本アプリが独自のサーバーに情報を保存・送信することはありません。

5. 第三者への提供

取得した情報を販売したり、広告目的で利用したり、第三者に提供したりすることはありません。

6. Google API サービスのユーザーデータポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他アプリへの転送は、Google API Services User Data Policy（限定使用の要件を含む）に従います。

7. アクセスの取り消し

利用者は Google アカウントの「サードパーティ製のアプリとサービス」 から、いつでも本アプリのアクセスを取り消せます。

Privacy Policy (English)

claude-workspace is a personal tool used only by its developer. With the user's permission, it accesses Gmail messages, Google Drive files and Google Calendar events solely to carry out the user's own instructions. Access tokens are stored only on the user's own computer; no data is sent to or stored on any server operated by this app. Data is never sold, used for advertising, or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account permissions page.
